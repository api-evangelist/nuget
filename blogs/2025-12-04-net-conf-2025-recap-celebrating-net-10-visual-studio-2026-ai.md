<p>At <a href="https://www.dotnetconf.net/">.NET Conf 2025</a> we celebrated the official launch of <a href="https://get.dot.net/10">.NET 10</a> and <a href="https://visualstudio.com/download">Visual Studio 2026</a>. The event provided a deeper dive into the world of .NET for developers worldwide and there were many announcements across the entire .NET ecosystem. Organized by Microsoft and the .NET community, the event was a huge success, providing .NET developers with 3 days of incredible, free .NET content, plus a special Student Zone on November 14th.</p>
<h2>On-Demand Recordings</h2>
<p>If you missed the event, feel free to catch up on the sessions via our on-demand playlists on <a href="https://aka.ms/dotnetconf25/OnDemand">YouTube</a>.</p>
<p></p>
<p>The conference kicked off with Scott Hanselman, .NET and Visual Studio product team members welcoming attendees and celebrating the incredible momentum of .NET. With over 7 million .NET developers using the Visual Studio family of products monthly and more than 23,000 pull requests merged to .NET 10 alone, the community continues to thrive. Since open-sourcing, .NET has received over 290,000 pull requests from the community, with more than 68,000 people contributing code and filing issues. Since 2020, .NET has been one of the highest velocity open-source projects tracked by the Cloud Native Computing Foundation (CNCF), and C# is consistently ranked in the top five programming languages on GitHub. Scott emphasized that the goal with .NET is to build &#8220;a complete development platform that developers love, that businesses trust&#8221; &#8211; a vision exemplified by how .NET powers many Microsoft products like Bing (running .NET 10 release candidates in production with noticeable P90 latency improvements), Xbox Gaming Copilot (using the entire .NET stack including Orleans and Aspire), and Copilot Studio (built as a Blazor WebAssembly app).</p>
<p><img alt=".NET Conf 2025 Keynote" src="https://devblogs.microsoft.com/dotnet/wp-content/uploads/sites/10/2025/12/keynote.webp" /></p>
<p>The keynote also highlighted the incredible ecosystem of partners contributing to .NET&#8217;s success, including distro maintainers and security partners like Red Hat, Canonical, and IBM; software partners like Syncfusion and Uno Platform helping build .NET MAUI and its core components; hardware partners AMD and Intel contributing low-level hardware intrinsics for significant performance improvements in computationally intensive tasks like AI workloads; and Samsung working on instruction set architecture for RISC-V and ARM, preparing .NET for a bright future.</p>
<p>Companies all over the world trust .NET to power their businesses every day. Throughout the conference, we heard inspiring customer stories. Shoreless AI, built entirely in .NET, demonstrated how the platform enables developers to become AI architects. In collaboration with Texas A&amp;M University&#8217;s Mays Business School, they powered the first-of-its-kind national AI pitch competition with over 100 applicants from 37 universities. FMG showcased the power of GitHub Copilot App Modernization by upgrading many of their applications to .NET 10 in just hours &#8211; a process that would typically take weeks.</p>
<p>A huge thank you to everyone who contributed to .NET!</p>
<p>This year, we delivered an action-packed program featuring the .NET team and community members across 3 days of live content:</p>
<ul>
<li><strong>Day 1: .NET 10 Launch (November 11)</strong> featured the official release of .NET 10, including the keynote and sessions led by the .NET team to introduce new features and enhancements including C# 14, performance improvements, ASP.NET Core updates, Blazor enhancements, .NET MAUI, Aspire, AI-powered development, and Visual Studio 2026.</li>
<li><strong>Day 2: Azure, Cloud, and Deep Dives (November 12)</strong> kicked off with the Azure Keynote and provided deeper dives into cloud-native development, Azure Container Apps, Azure Kubernetes Service, Azure Functions, AI services, and advanced topics including testing, containers, and security.</li>
<li><strong>Day 3: Community Day (November 13)</strong> featured speakers from around the world sharing real-world experiences, advanced techniques, and innovative projects built with .NET. The day included live sessions followed by a YouTube Premiere track featuring even more community content.</li>
</ul>
<p>We also extended .NET Conf&#8217;s reach to developers in China through localized broadcasts on WeChat and Bilibili, featuring Chinese subtitles and region-specific scheduling. This effort engaged the vibrant Chinese .NET developer community and demonstrated our commitment to supporting .NET developers worldwide. 你好，中国的 .NET 开发者朋友们！.NET 爱你们！ (Hello to our .NET developer friends in China! .NET loves you!)</p>
<h2>.NET Conf 2025 Announcements</h2>
<p>As part of the keynotes of .NET Conf 2025, we had exciting announcements from the teams at Microsoft:</p>
<h3>.NET 10 is now available</h3>
<p>The best version of .NET yet is now available! .NET 10 is released and ready to download today. This Long Term Support (LTS) release delivers a complete development platform that developers love and businesses trust, enabling you to build modern apps with a high-performance runtime, best-in-class programming languages, and powerful development tools. With updates across ASP.NET Core, .NET MAUI, WinForms, Blazor, C# 14, industry-leading performance improvements, enhanced security, and so much more, .NET 10 empowers you to meet the needs of tomorrow. As an LTS release, .NET 10 will be supported for three years until November 10, 2028.</p>
<p><a href="https://aka.ms/dotnet10">Read the announcement</a> | <a href="https://get.dot.net/10">Download .NET 10</a></p>
<h3>Visual Studio 2026 released</h3>
<p>Visual Studio 2026 is now available, delivering best-in-class development tools as part of the complete .NET development platform! This release includes full .NET 10 support, a modern look and feel with FluentUI, improved hot reload and Razor editing experiences, enhanced diagnostics, streamlined upgrade processes, and GitHub Copilot as your AI pair programmer. Together with .NET 10, Visual Studio 2026 provides the tools developers love to build the modern applications that businesses trust.</p>
<p><img alt="Visual Studio 2026 release announcement" src="https://devblogs.microsoft.com/dotnet/wp-content/uploads/sites/10/2025/12/keynote-visual-studio.webp" /></p>
<p><a href="https://aka.ms/vs2026ga">Read the announcement</a> | <a href="https://visualstudio.com/download">Download Visual Studio 2026</a></p>
<h3>Aspire 13 is here</h3>
<p>Aspire is now more than just .NET. Featuring a code-first experience to help you build applications with modular and extensible integrations with popular frameworks and tools, Aspire 13 gives you the flexibility to build and deploy applications your way.</p>
<p><a href="https://aka.ms/aspire/13/blog">Read the announcement</a> | <a href="https://aka.ms/aspire/13/download">Download Aspire</a></p>
<h3>GitHub Copilot app modernization</h3>
<p>You can now use GitHub Copilot for app modernization! Quickly upgrade your .NET applications to the latest versions of .NET with the power of AI. Get code suggestions, end-to-end assessments and remediation assistance to help you modernize your applications and migrate to Azure.</p>
<p><a href="https://aka.ms/ghcp-appmod/net">Learn more</a></p>
<h3>GitHub Copilot testing for .NET</h3>
<p>Use GitHub Copilot to improve your test coverage! Now in public preview, generate unit tests, cover more edge cases, accelerate your testing, and give yourself a productivity boost. Copilot can even suggest fixes when a test fails to help ensure your applications are working as expected.</p>
<p><a href="https://aka.ms/ghcp-testing/learn">Try the Learn module</a></p>
<h3>Microsoft Agent Framework for .NET</h3>
<p>The Microsoft Agent Framework for .NET is now available in public preview! As part of the complete .NET platform, the framework enables you to build intelligent AI-powered agents and assistants that can autonomously perform tasks, make decisions, and interact with users using natural language. The framework is designed to work seamlessly with the broader .NET ecosystem, including Microsoft.Extensions.AI and other .NET technologies.</p>
<p><img alt=".NET Conf 2025 Keynote - Agentic UI" src="https://devblogs.microsoft.com/dotnet/wp-content/uploads/sites/10/2025/12/agentic-ui.webp" /></p>
<p><a href="https://github.com/microsoft/agent-framework">Learn more</a></p>
<h3>MCP C# SDK</h3>
<p>The Model Context Protocol (MCP) C# SDK is now available in public preview! MCP enables AI applications to connect with external tools and data sources, extending the capabilities of AI agents. Microsoft products are already leveraging this technology &#8211; both Xbox Gaming Copilot and Copilot Studio (a Blazor WebAssembly app) use the MCP C# SDK in production. The SDK provides a set of tools and libraries to help you build intelligent applications with extensible AI capabilities.</p>
<p><a href="https://modelcontextprotocol.github.io/csharp-sdk/">Learn more</a></p>

<h2>Key Features and Improvements in .NET 10</h2>
<h3>Unparalleled Performance</h3>
<p>.NET 10 is the fastest .NET yet with improvements across the runtime, workloads, and languages. Watch <a href="https://www.youtube.com/watch?v=snnULnTWcNM">Performance Improvements in .NET 10</a> for a deep dive. Key improvements include:</p>
<ul>
<li><strong>JIT compiler enhancements</strong>: Better inlining, method devirtualization, and improved code generation</li>
<li><strong>Hardware acceleration</strong>: AVX10.2 support for cutting-edge Intel silicon, Arm64 SVE for advanced vectorization</li>
<li><strong>NativeAOT improvements</strong>: Smaller, faster ahead-of-time compiled apps</li>
<li><strong>Runtime optimizations</strong>: Enhanced loop inversion and stack allocation strategies</li>
</ul>
<h3>Security &amp; Cryptography</h3>
<p>With quantum computing on the horizon, .NET 10 expands post-quantum cryptography support with Windows Cryptography API: Next Generation (CNG) support, ensuring your applications are prepared for the future of computing. Additional security enhancements throughout .NET 10 help protect your applications with hardened defaults and improved cryptographic capabilities.</p>
<p>Learn more in <a href="https://www.youtube.com/watch?v=8lFm4wI1bPo">A Year in .NET Security (2024–2025)</a> and <a href="https://www.youtube.com/watch?v=nxUz7OQO3n8">Security-First .NET: How GitHub&#8217;s Tools Protect Your Open-Source Projects</a>.</p>
<h3>C# 14 &amp; F# 10</h3>
<p>C# 14 introduces powerful features including field-backed properties, extension properties and methods, first-class <code>Span&lt;T&gt;</code> conversions, and partial properties and constructors. F# 10 focuses on clarity, consistency, and performance with scoped warning suppression, access modifiers on auto property accessors, and parallel compilation. Learn more in <a href="https://www.youtube.com/watch?v=xy-HzFp0pbA">What&#8217;s New in C# 14</a> and <a href="https://www.youtube.com/watch?v=GcEHiY6Vp-8">Smatterings of F#</a>.</p>
<h3>Cloud-Native Development with Aspire</h3>
<p>Aspire 13 makes building observable, production-ready distributed apps straightforward with:</p>
<ul>
<li>Modern development experience with CLI enhancements</li>
<li>Seamless build &amp; deployment with built-in static file site support</li>
<li>Enterprise-ready infrastructure with flexible connection strings</li>
<li>Polyglot support for Python, JavaScript, and other languages</li>
</ul>
<p>Watch <a href="https://www.youtube.com/watch?v=aXouOsBh4ro">Aspire: Cloud-Native Development Simplified</a>, <a href="https://www.youtube.com/watch?v=UQiL3nbQbtM">Deep Dive: Extending and Customizing Aspire</a>, and <a href="https://www.youtube.com/watch?v=dJdXdRiIfDw">Aspire Unplugged with David and Maddy</a> for more details.</p>
<h3>Artificial Intelligence</h3>
<p>.NET 10 brings comprehensive AI capabilities:</p>
<ul>
<li><strong>Microsoft Agent Framework</strong>: Build intelligent multi-agent systems with sequential, concurrent, and handoff workflows</li>
<li><strong>Microsoft.Extensions.AI</strong>: Unified abstractions for integrating AI services with any provider</li>
<li><strong>Model Context Protocol (MCP)</strong>: Extend AI agents with external tools and services</li>
<li><strong>AG-UI Support</strong>: Build rich agent user interfaces with the AG-UI protocol</li>
</ul>
<p>Explore these sessions: <a href="https://www.youtube.com/watch?v=N0DzWMkEnzk">Building Intelligent Apps with .NET</a>, <a href="https://www.youtube.com/watch?v=V_sIYwc9Tvs">Understanding Agentic Development</a>, <a href="https://www.youtube.com/watch?v=3swFQjBZDUA">Model Context Protocol (MCP) for .NET Developers</a>, <a href="https://www.youtube.com/watch?v=b9cwTqr1cKo">Building Remote MCP Servers</a>, <a href="https://www.youtube.com/watch?v=Pz3A3CCgEac">Build smarter agents with Redis, .NET and Agent Framework</a>, and <a href="https://www.youtube.com/watch?v=eJfToDv8KH4">AI Foundry for .NET Developers</a>.</p>
<h3>ASP.NET Core Enhancements</h3>
<p>ASP.NET Core in .NET 10 includes:</p>
<ul>
<li><strong>Automatic Memory Pool Eviction</strong>: Reduces memory footprint in long-running applications</li>
<li><strong>Enhanced Security</strong>: Passkey support in Identity, hardened defaults, improved certificate handling, and enhanced security headers ensure your apps are secure by default</li>
<li><strong>Native AOT Enhancements</strong>: OpenAPI support in the webapiaot template</li>
<li><strong>Blazor improvements</strong>: Component state persistence, circuit state persistence, and improved form validation</li>
</ul>
<p>Learn more in <a href="https://www.youtube.com/watch?v=LgUZB_rhyX4">What&#8217;s New in ASP.NET Core</a>, <a href="https://www.youtube.com/watch?v=V0Af7y7aMBE">Build better web apps with Blazor in .NET 10</a>, and the <a href="https://www.youtube.com/watch?v=DqoxPIDNWfA">.NET Conf 2025 release roundup on ASP.NET Community Standup</a>.</p>
